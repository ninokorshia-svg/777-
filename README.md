# ფიზიკის ინტერაქტიული ქვიზი და მასწავლებლის პანელი
## Interactive Physics Quiz and Teacher Dashboard (VIII Grade)

სრული საგანმანათლებლო ვებ-აპლიკაცია VIII კლასის ფიზიკის შემაჯამებელი ტესტირებისთვის თემაზე: **„მექანიკური მოვლენები — მუშაობა, სიმძლავრე, კინეტიკური და პოტენციური ენერგია“**.

აპლიკაცია აგებულია თანამედროვე ტექნოლოგიურ დასტაზე, სრულად ოპტიმიზებულია და მზადაა **Cloudflare Workers + Cloudflare D1 Database**-ზე განთავსებისთვის, ასევე მუშაობს ადგილობრივ გარემოში Node.js და SQLite-ის მეშვეობით.

---

## ძირითადი ფუნქციონალი

### 1. მოსწავლის მოდული (`StudentQuiz`)
- **15 შემოწმებული საგამოცდო საკითხი**: დაყოფილი 3 დონედ (5 მარტივი - 1ქ, 5 საშუალო - 2ქ, 5 რთული - 3ქ, ჯამში 30 ქულა).
- **ავტომატური რანდომიზაცია**: ყოველ გახსნაზე კითხვების თანმიმდევრობა და 4 სავარაუდო პასუხი (ა, ბ, გ, დ) შემთხვევითად ნაწილდება.
- **პასუხების უსაფრთხოება**: სწორი პასუხები არ იგზავნება საჯარო API-ში წინასწარ. მოსწავლე ვერ ამოიღებს პასუხებს ბრაუზერის Network ჩანართიდან.
- **განმავითარებელი უკუკავშირი**: პასუხის დაფიქსირების შემდეგ მოსწავლე იღებს მოკლე პედაგოგიურ განმარტებას და მინიშნებას.
- **სამდონიანი შეფასება**:
  - `85% - 100%`: გაფართოებული / შემოქმედებითი დონე (ნიშნები 9-10)
  - `60% - 84%`: დამოუკიდებელი დონე (ნიშნები 6-8)
  - `< 60%`: საჭიროებს მხარდაჭერას (ნიშნები 1-5)
- **განმეორებითი შევსების ბლოკირება**: ტესტის დასრულების შემდეგ თავიდან დაწყების ღილაკი ამოღებულია და იმავე მოწყობილობიდან ან სახელით/ნომრით განმეორებითი შესვლა ავტომატურად იბლოკება.

### 2. მასწავლებლის მართვის პანელი (`TeacherDashboard`)
- **100 დაცული ანგარიში (`Teachers1` - `Teachers100`)**: თითოეული მასწავლებელი ირჩევს თავის უნიკალურ კოდს და იცავს მას პირადი პაროლით (PBKDF2-SHA256).
- **მონაცემთა სრული იზოლაცია**: მასწავლებელი A ვერასდროს ნახავს ან წაშლის მასწავლებელი B-ს მონაცემებს.
- **რეალურ დროში ჟურნალი**: მოსწავლეთა მიერ გაგზავნილი შედეგები მყისიერად ჩნდება ჟურნალში.
- **ანალიტიკა და სამოქმედო გეგმა**: კლასის საშუალო ქულა, ნიშნების გადანაწილება და თემატური დიაგნოსტიკა (მუშაობა, სიმძლავრე, კინეტიკური ენერგია, პოტენციური ენერგია, მ.ქ.კ.).
- **ტესტის რედაქტორი**: მასწავლებელს შეუძლია შეცვალოს კითხვების ტექსტი, ქულები, ილუსტრაციები ან დააბრუნოს პირვანდელ შაბლონზე.
- **ექსპორტი (CSV)**: შედეგების ჩამოტვირთვა Excel/Google Sheets-თან თავსებად ფორმატში.
- **გაზიარება და QR კოდი**: მოსწავლისთვის ინდივიდუალური ლინკის გენერირება და კოლეგებთან გაზიარება.

## არქიტექტურა და უსაფრთხოება

- **Cloudflare D1 Database**: სერვერლეს რელაციური SQLite ბაზა Edge-ზე.
  - `teachers`: ანგარიშები, PBKDF2 პაროლის ჰეში და Salt.
  - `teacher_sessions`: დაცული 256-ბიტიანი სესიის ტოკენები.
  - `teacher_quizzes` & `quiz_versions`: ტესტების ვერსიონირება (ისტორიული ნიშნები არ ფუჭდება ტესტის რედაქტირებისას).
  - `student_submissions`: მოსწავლეთა ნაშრომები `UNIQUE(teacher_id, student_identifier)` შეზღუდვით.
  - `login_rate_limits`: ბრუტფორსისგან დაცვა (5 არასწორი მცდელობის შემდეგ დროებითი ბლოკი).
  - `audit_logs`: მნიშვნელოვანი მოვლენების აუდიტი.
- **Cloudflare Worker**: `worker/index.ts` იყენებს Web Standard Request/Response API-ს და აკავშირებს `env.DB`-ს.
- **Zero-drift ლოკალური ადაპტერი**: ადგილობრივ დეველოპმენტში (`server.ts`) გამოიყენება Node.js 22-ის ჩაშენებული `node:sqlite`, რომელიც სრულად იმეორებს Cloudflare D1-ის ქცევას.

## გაშვება და ბრძანებები

### ლოკალური დეველოპმენტი
```bash
npm run dev
```
აპლიკაცია გაეშვება `http://localhost:3000`-ზე.

### ტესტირების გაშვება
```bash
node scripts/test_security_and_cf.js
```
ამოწმებს 18 უსაფრთხოების, ავტორიზაციისა და ბაზის მთლიანობის მოთხოვნას.

### Frontend-ის აწყობა
```bash
npm run build
```

### Cloudflare-ზე განთავსება
იხილეთ დეტალური გზამკვლევი ქართულ ენაზე ფაილში: **[DEPLOYMENT_GEORGIAN.md](./DEPLOYMENT_GEORGIAN.md)**.
```bash
npm run cf:d1:init    # მიგრაციების გაშვება D1 ბაზაში
npm run cf:deploy     # აპლიკაციის განთავსება Cloudflare Workers-ზე
```
